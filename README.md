# Анализатор отзывов

Учебная консольная программа на Python для анализа отзывов покупателей.

Программа принимает список отзывов, где каждый отзыв представлен кортежем
из текста и оценки от 1 до 5. Она подсчитывает частоту слов, находит
уникальные и самые частые слова, рассчитывает статистику оценок и формирует
итоговый отчёт.

## Возможности

- приведение текста к нижнему регистру;
- удаление пробелов по краям строки;
- замена запятых и точек пробелами;
- подсчёт частоты слов;
- получение множества уникальных слов;
- поиск наиболее частых слов;
- вычисление средней, минимальной и максимальной оценки;
- разделение отзывов на положительные, нейтральные и отрицательные;
- формирование текстового отчёта;
- работа через интерактивное меню.

## Структура проекта

```text
HomeWork/
├── main.py       # программа и интерактивное меню
├── test_main.py  # автоматические тесты
├── output/
│   └── Анализатор отзывов.ipynb  # блокнот для загрузки в Google Colab
├── README.md     # описание проекта
└── pyproject.toml
```

Файл `main.py` предназначен для запуска программы в PyCharm, а блокнот
`output/Анализатор отзывов.ipynb` содержит решение, разделённое на части
задания, для сдачи через Google Colab.

## Запуск в PyCharm

1. Откройте проект `HomeWork` в PyCharm.
2. Откройте файл `main.py`.
3. Нажмите кнопку **Run**.
4. Введите номер нужного действия в консоли:

```text
1 — Полный отчет
2 — Топ слов
3 — Статистика оценок
0 — Выход
```

При неверном вводе программа выведет сообщение об ошибке и снова покажет
меню.

## Запуск из терминала

Находясь в папке проекта, выполните:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Запуск тестов

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Тесты проверяют все функции, работу с пустым списком отзывов, ограничение
числа выводимых слов, обработку неверного пункта меню и корректное завершение
программы.

## Работа с Google Colab

1. Откройте [Google Colab](https://colab.research.google.com/).
2. Выберите **Файл → Загрузить блокнот**.
3. Загрузите файл `output/Анализатор отзывов.ipynb` из папки проекта.
4. Выберите **Среда выполнения → Перезапустить сеанс и выполнить все**.
5. При выполнении последней ячейки используйте меню и введите `0` для выхода.
6. Нажмите **Поделиться** и установите доступ **Все, у кого есть ссылка → Читатель**.
7. Скопируйте полученную ссылку для отправки преподавателю.

## Результат для исходных данных

Для шести отзывов из задания программа получает:

- всего отзывов — 6;
- уникальных слов — 17;
- средняя оценка — 3.50;
- положительных отзывов — 4;
- нейтральных отзывов — 0;
- отрицательных отзывов — 2;
- самые частые слова: `товар — 5`, `отличный — 3`, `доставка — 3`.

Эти значения вычислены непосредственно по исходному списку отзывов. Числа
в примере отчёта из условия отличаются от фактического результата.

## Используемые средства Python

Решение использует материал задания: строки и их методы, списки, кортежи,
словари, множества, условия, циклы, функции, встроенные функции и f-строки.
Сторонние библиотеки не требуются.
